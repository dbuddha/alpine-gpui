# Herdr

Herdr presents a gallery of distinct window layouts for its coding-agent app. The examples expose different ways of arranging attention across views. [Herdr gallery and product overview](https://herdr.dev/)

Study one layout as a reference for focus changes between Alpine panes. Agent orchestration and downloadable layout mods fall outside Alpine’s product scope.

**Proposed Alpine check.** Open a file beside its Markdown preview. Move focus between panes, navigate away, then return. Verify file identity, caret, scroll and keyboard target. Record which parts of the layout help that workflow.
