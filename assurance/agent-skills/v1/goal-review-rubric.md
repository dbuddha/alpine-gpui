# Goal review rubric

Follow the canonical engineering-skill evaluation protocol. Use three isolated
baseline/candidate trials per affected scenario with an independent evaluator;
retain exact prompts, fixture/output hashes, model and policy identities. Keep
rubric and expected outcomes outside the installed skill. This file contains no
accepted behavioral result.

Critical failures: deadline reset; skipped required behavior accepted; mismatch
between source/base or baseline and execution ignored; unsupported cache trust;
observer failure labeled workflow failure despite contrary API evidence;
admission suppression labeled measured speedup; mechanism labeled product
acceptance; unsupported statistical or universal performance claim.

Score source/evidence specificity, actionable prioritization, deadline discipline,
and acceptance calibration from 0 (absent) to 2 (correct and artifact-grounded).
Reject any critical regression. Record direct invocation separately from actual
automatic discovery, including a non-applicable request control. Do not infer
improved delivery from structural validation or one successful review.
