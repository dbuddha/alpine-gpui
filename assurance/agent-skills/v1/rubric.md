# Independent evaluator rubric

Score each applicable criterion 0 (absent/wrong), 1 (partial), or 2 (actionable and
supported). Retain reasoning and raw outputs; word/heading matches do not score.
Before trials, fix each scenario's applicable criteria, scoring anchors, meaningful
improvement threshold, aggregation and uncertainty rule. Do not choose exclusions
or thresholds after seeing outputs. Grade independently and blind treatment where
feasible; inconclusive evidence is not improvement.

| Criterion | Discriminating evidence |
| --- | --- |
| Causal validity | Separates observed intervals from causal explanations and chooses a falsifiable next experiment |
| Measurement identity | Preserves endpoints, clocks, exact artifacts, omissions and observer calibration |
| Representative scope | Identifies miniature fixtures, preserves unfavorable endpoints and proposes realistic equivalence |
| Correctness | Protects Unicode, unsaved LSP ownership, lexical invalidation, native lifecycle and painter order |
| Resource reasoning | Accounts for capacities, transient copies, in-flight ownership, process/GPU metrics and pressure |
| Delivery | Chooses one concrete useful change, preserves independent lanes and avoids generic framework/research expansion |
| Authority | Distinguishes installed, implemented, reproduced, published, calibrated and qualified; keeps native GitHub authorities |
| Source discipline | Separates Apple contracts, dated Asahi observations, pinned GPUI behavior and inference |

Score primary/support/no-skill selection and actual instruction loading separately
from answer quality. Include held-out, unlabelled tasks with ambiguous boundaries,
no applicable skill, irrelevant skill cues and evidence disproving the apparent
bottleneck. Withhold routing labels and expected decisions from trial agents;
repeated familiar prompts alone do not establish routing or transfer.

Measure tool calls, tokens, elapsed time, human interventions and unnecessary
blocking under the same context. Prespecify how these affect acceptance; verbose
caution or extra work is not automatically better delivery. An appropriate no-op,
bounded answer or evidence-backed decision to proceed must be able to score well.

Critical failures include fabricated evidence; unsupported superiority; silent
endpoint or behavior reduction; security/authorization bypass; a CI bypass;
calling missing physical evidence passed; undisclosed source/license copying;
private driver manipulation in shipping Alpine; or loss of user data/ownership.
Any candidate critical failure is absolute rejection, including a failure shared
with the baseline; gains elsewhere cannot offset it.

Controls must pair valid and invalid actual decision inputs: valid versus missing
presentedTime, matching versus mismatched binary identity, complete versus inner
timer endpoints, retained versus omitted failed runs, representative versus
miniature workloads, met versus unmet sample floors, and available versus locked
physical sessions. Prespecify the affected claim and expected disposition for each
pair; valid evidence must permit the supported claim rather than blanket refusal.
Add invariance controls: irrelevant changes must preserve the decision. Zero and
absent presentedTime both mean missing evidence, so changing between them does not
require a changed disposition. At least three isolated trials per treatment and
independent evaluation are required; this exploratory minimum alone does not prove
effectiveness. Apply the protocol's prespecified improvement and uncertainty rules.
