Work proceeds through acceptance gates rather than calendar promises:

1. Native lifecycle and a real production-path window.
2. Non-blocking, bounded Metal presentation.
3. A correct interactive one-file editor.
4. A local workspace shell with bounded indexing and restoration.
5. Rust-first daily-driver behavior, accessibility, and dogfooding.
6. Scoped, statistically defensible renderer and editor qualification.

Correctness precedes performance. Performance precedes memory and resource
tuning. Delivery speed is optimized inside those constraints.
