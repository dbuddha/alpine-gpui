Alpine adopts only publicly supportable lessons: a purpose-built UI stack, GPU
batching, asynchronous saving, low-priority indexing, incremental index work,
lazy loading, graceful large-search degradation, and avoidance of unnecessary
redraw.

Sublime Text is proprietary. Private text, cache, and scheduling internals are
not treated as facts. Product measurements describe externally observed
behavior and never infer hidden implementation.
