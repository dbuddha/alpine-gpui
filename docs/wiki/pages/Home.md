# Alpine GPUI and Alpine Studio

> Retrieval mirror synchronized from Alpine `main` revision
> `{{ALPINE_MAIN_REVISION}}`. The repository mdBook is canonical.

Alpine GPUI is an Apple-first, correctness-gated GPU UI framework. Alpine
Studio is its local-only editor proving ground: a fast solo developer tool with
no collaboration, hosted AI, cloud account, telemetry, plugin host, remote
development, or marketplace.
