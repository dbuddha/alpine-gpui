# Documentation authority and Wiki policy

> Retrieval mirror synchronized from Alpine `main` revision
> `{{ALPINE_MAIN_REVISION}}`. The repository mdBook is canonical.

Requirements, AEPs, research, decisions, evidence, and qualification records
live in the repository and render through mdBook. The GitHub Wiki is a curated,
one-way retrieval mirror generated from reviewed repository templates.

Wiki pages must identify their exact source revision and canonical document.
They may not contain unique claims or evidence. Publication accepts only the
approved manifest, only from clean exact `origin/main`, and never broadens a
dependency or architecture decision.

Canonical source: [Wiki mirror policy](https://github.com/dbuddha/alpine-gpui/blob/{{ALPINE_MAIN_REVISION}}/docs/wiki/README.md)
