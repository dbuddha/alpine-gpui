# Use cases

Use cases record stable user outcomes and substantial journeys. A GitHub
Capability owns approval and current status; its Requirements own atomic,
testable behavior. A use case changes only when the intended user outcome
changes, not when an implementation task moves between columns.

The primary journeys are the [desktop application foundation](desktop-application.md)
and [Alpine Studio high-fidelity](alpine-studio-highfidelity.md).

Future journeys will cover text editing, large virtualized data, multi-window
tools, embedded media, and accessible component composition only when their
Capabilities are ready for owner review.
