# Case studies

Each case study records a conclusion about an immutable upstream revision.
Findings explain design choices; they are not proof that Alpine implements or
satisfies a behavior. Linked research issues preserve investigation history.

The editor references cover the pinned [Zed application](zed-editor.md),
[Zed GPUI and macOS renderer](zed-gpui.md), and
[Sublime Text local-speed model](sublime-editor.md). Zed findings identify exact
source locations. Sublime findings distinguish official facts, inference and
unknown proprietary internals.

Revisit a finding when a concrete development question warrants it. Preserve old
source identities and qualify new conclusions. Source copying still needs owner
authorization, exact provenance and compatible licensing.
