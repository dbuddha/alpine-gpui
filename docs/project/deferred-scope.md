# Deferred and rejected scope

The private daily-driver path is protected from feature breadth that weakens
correctness, responsiveness, memory efficiency, or delivery of the accepted
local editor. A deferred item is not silently accepted future work.

## Excluded from the private daily driver

- Collaboration and multiplayer editing.
- Hosted AI or an agent product.
- Cloud accounts, synchronization, or remote development.
- Telemetry or network analytics.
- Plugin API, extension host, marketplace, or executable grammar ecosystem.
- Debugger workflow.
- Integrated terminal, task runner, and Git UI.
- Multi-window qualification.
- Linux and Windows implementation.
- Public packaging, signing, notarization, update service, and release support.

Requirement [#35](https://github.com/dbuddha/alpine-gpui/issues/35) protects
terminal, task, and Git UI deferral. External terminal and Git tools remain the
supported private-dogfood workflow. Post-dogfood consideration does not make
these M5 exit criteria.

## Framework and renderer exclusions

- GPUI as a shipping dependency or source-compatibility target.
- WGPU, `wgpu-hal`, Naga, WGSL, or WebGPU in shipping crates.
- Tokio or a general asynchronous runtime.
- GPUI's retained entity graph, reactive globals, or distributed registration.
- Browser CSS, DOM semantics, or a general flexbox engine.
- A general component or element framework before concrete Studio reuse and
  measured need.
- Game-engine render graphs, ECS render worlds, continuous rendering, 3D asset
  pipelines, materials, physics, scene streaming, MetalFX, or generalized
  animation infrastructure.

Editor-relevant resource lifetime, triple buffering, deadline measurement,
batched primitives, bounded reuse, and offline preparation of built-in assets
remain acceptable techniques. Their game-industry origin does not authorize a
game-engine architecture.

## Deferred platform path

[M6](https://github.com/dbuddha/alpine-gpui/milestone/7) owns possible Vulkan,
Wayland, D3D12, and Win32 outcomes. It is independent of the Apple Silicon
private daily driver and macOS version 1. Shared safe value contracts may remain
portable, but no Linux or Windows runtime work belongs on the current product
critical path without a new approved platform requirement.

## Comparator boundaries

- Pinned GPUI and Zed are semantic and performance comparators, not product
  dependencies.
- WGPU is a source-research and possible differential-validation input.
- awesome-gpui is workload discovery until a selected project receives a pinned
  source audit.
- Sublime Text supplies public product and externally measurable lessons; its
  proprietary internals are not inferred.

## Re-entry gate

Deferred work may enter an active path only when:

1. A capability or requirement states the observable user outcome and receives
   visible owner approval.
2. Its dependencies, ownership, failure behavior, and acceptance evidence are
   explicit.
3. Startup, latency, binary size, memory, unsafe, licensing, maintenance, and
   transitive costs are measured where applicable.
4. The Project and milestone path show what accepted work moves or becomes
   blocked.
5. The change does not weaken an earlier correctness, performance, or memory
   gate.
6. Canonical product, architecture, lineage, and release documentation is
   updated through a reviewed pull request.

Research interest, comparator feature parity, or implementation availability is
not sufficient for re-entry.
