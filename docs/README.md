# Engineering guide

This guide contains durable product and engineering knowledge that cannot be
recovered reliably from source alone. It is deliberately smaller than a
product-management system. GitHub owns live research, priority, approval,
implementation tasks, pull requests, CI results, and releases.

Read [Vision and mission](vision.md) for the stable principles. Begin concrete
work from an approved GitHub Capability and Requirement. Read an AEP only when
the task links it, and follow its atomic claims into the machine-checked
[evidence registry](../assurance/evidence.toml).

Documentation is tested source. Code examples must compile, links must resolve,
and implemented architectural truth must remain in the root
[Architecture](../ARCHITECTURE.md). Historical AEPs and dated case studies are
superseded instead of silently rewritten.
